# Сайт Юлии Ларюшкиной

Техническая основа персонального сайта брокера по недвижимости в Рязани и Рязанской области. Сейчас реализованы только статические страницы и общая навигация. Дизайн, модель объявлений и функциональность каталога будут разработаны отдельно.

## Технологии

HTML, CSS и небольшой генератор на стандартной библиотеке **Python 3.12 или новее**. Python нужен только разработчику для сборки и локального просмотра. На хостинг загружаются готовые HTML и CSS из `dist/`; Python, сервер приложения и база данных на хостинге не нужны.

Внешних зависимостей нет: установка пакетов, npm и lock-файл не требуются. Фильтры и сортировку позже можно реализовать обычным JavaScript в браузере. Генератор создаёт настоящий `index.html` для каждого адреса, поэтому прямые ссылки работают без SPA-перенаправлений.

## Начало работы на Windows

Установите Python 3.12+ с python.org, включая Python Launcher. Откройте PowerShell в папке проекта:

```powershell
py -3 --version
py -3 scripts/site.py dev
```

Откройте `http://127.0.0.1:8000/`. Остановка — Ctrl+C. Команда `dev` сначала собирает сайт, затем запускает локальный просмотр. После редактирования исходников остановите и повторите команду: автоматического обновления нет. Если команда `py` недоступна, используйте `python` нужной версии.

Сборка, проверка и просмотр готового результата:

```powershell
py -3 scripts/check.py
py -3 scripts/site.py build
py -3 scripts/site.py preview
```

`preview` ничего не пересобирает. Порт можно изменить: `--port 8080`. Локальный сервер слушает только `127.0.0.1`; это инструмент разработки. Не открывайте HTML через `file://`: проверяйте сайт по HTTP.

## Корень домена и GitHub Pages

Постоянная настройка находится в `site.toml`:

```toml
base_path = "/"
include_demo = true
```

Для размещения в подпапке задайте `base_path = "/yulia-ryazan-realty/"`. Можно временно переопределить путь без изменения конфигурации:

```powershell
py -3 scripts/site.py build --base-path /yulia-ryazan-realty/
py -3 scripts/site.py preview --base-path /yulia-ryazan-realty/
```

Откройте:

- `http://127.0.0.1:8000/yulia-ryazan-realty/`
- `http://127.0.0.1:8000/yulia-ryazan-realty/catalog/`
- `http://127.0.0.1:8000/yulia-ryazan-realty/about/`
- `http://127.0.0.1:8000/yulia-ryazan-realty/contacts/`
- `http://127.0.0.1:8000/yulia-ryazan-realty/objects/demo/`

Последний адрес открывайте напрямую и обновляйте страницу. Путь при сборке и просмотре должен совпадать. Для возврата к корню повторите обе команды с `--base-path /`.

В `dist/` всегда находятся файлы относительно корня сайта, без дополнительной папки `yulia-ryazan-realty`. При будущей публикации на GitHub Pages содержимое `dist/` будет артефактом сайта; на обычном хостинге его нужно положить в выбранную корневую папку или подпапку. Хостинг должен отдавать `index.html` из каталогов. Ссылки и CSS получают префикс при сборке. Для будущих изображений и скриптов используйте в HTML `${base}images/...` и `${base}assets/...`; в CSS используйте пути относительно самого CSS-файла.

Файл `.nojekyll` добавляется автоматически. Публикация, GitHub Actions и настройки удалённого репозитория на этом этапе не настроены.

## Структура

```text
site.toml                     базовый путь и включение демо
scripts/site.py               генерация и локальный просмотр
scripts/check.py              интеграционные проверки
src/templates/layout.html     общая шапка, навигация, подвал, метаданные
src/pages/                    главная, каталог, обо мне, контакты
src/demo/routing-example.html отдельный демонстрационный шаблон
src/data/                     место для будущих данных объявлений
public/assets/styles.css      базовые адаптивные стили
public/images/                место для будущих фотографий
dist/                         результат сборки, исключён из Git
```

Генератор использует `string.Template`: `${base}` — базовый путь, `${demo_link}` — условная ссылка на демо в каталоге. Буквальный знак доллара в шаблонах записывайте как `$$`. Содержимое сейчас — доверенные HTML-файлы разработчика. При добавлении генерации из данных нужно экранировать текстовые значения и проверять адреса ресурсов.

Каждая сборка заменяет `dist/`. Не редактируйте эту папку вручную и не храните в ней исходные материалы.

## Временные разделы и подготовка к запуску

Главная содержит только имя, профессию и регион из задания. Каталог пуст; «Обо мне» и «Контакты» содержат временные подписи. Телефон, MAX, сведения об опыте, услуги и отзывы не придуманы и не добавлены. Форм сбора данных нет.

`objects/demo/` — только проверка маршрутизации, явно помеченная как демонстрация. Чтобы убрать её и ссылку из каталога, установите `include_demo = false` в `site.toml` и пересоберите сайт. Однократный вариант: `py -3 scripts/site.py build --no-demo`. Проверка гарантирует, что при такой пересборке не остаётся старой страницы.

Все страницы временно содержат `noindex, nofollow` и уведомление о подготовке сайта. Перед публичным запуском после согласования содержания удалите их из общего шаблона, отключите демо и проверьте контакты.

## Проверки

`py -3 scripts/check.py` без внешних пакетов собирает сайт во временной папке и проверяет по HTTP:

- все пять страниц в корне и подпапке `/yulia-ryazan-realty/`;
- прямую загрузку и повторное открытие каждого адреса;
- внутренние ссылки, CSS и наличие цели ссылки «К содержимому»;
- настоящие ответы 404 для отсутствующих адресов;
- отключение демо и удаление его страницы при пересборке.

Мобильный вид проверьте в браузере на ширине 360 и 390 px: навигация должна переноситься, текст и кнопки помещаться без горизонтальной прокрутки, клавиатурный фокус быть видимым. Автоматическая HTTP-проверка не заменяет визуальную проверку.

## Дальнейшее обновление

1. Юлия передаёт подтверждённые сведения и фотографии разработчику.
2. Разработчик передаёт Codex задачу обновить исходники и данные в репозитории.
3. Разработчик проверяет изменения, сборку, страницы и мобильный вид.
4. После отдельного согласования выполняются коммит, push и публикация.

На следующем этапе нужно согласовать поля объявлений, правила адресов и снятия с публикации, подготовку фотографий и фильтры. Тип объекта (квартира, дом, участок и другие) и первичный/вторичный рынок должны быть разными характеристиками. Окончательная схема данных сейчас не задана.

Добавляйте только информацию, предназначенную для публичного сайта. Не сохраняйте в проекте секреты, документы и персональные данные собственников. Файлы `.env`, виртуальные окружения, Python-кеши и сборка исключены через `.gitignore`.
